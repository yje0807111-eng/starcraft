# 기본 유닛·건물 수치 (SC 원본 기준 공통 자료)

> 스타크래프트(브루드워) 원본 수치를 이 게임의 종족·유닛명에 매핑한 **기본 공통 자료**.
> 관리자 페이지(샌드박스: 메인·건설·유닛 패널)에 적용하는 단일 기준.
> - **공격 속도(쿨다운 프레임)**: 공격 간 대기 프레임. 작을수록 빠름. *가장 빠름 속도 기준 24프레임 = 1초.*
> - **이동 속도(px/frame)**: 1프레임당 이동 픽셀. 클수록 빠름. (기본 보병 1.88)
> - **공격력 타입**: 일반형(모든 크기 100%) / 진동형(소 100·중 50·대 25) / 폭발형(소 50·중 75·대 100)
> - 게임 코드 반영 위치: `sc-ums-web.html`의 `TECH_SPEC`(건설 탭), `U`(메인 전투).

## 적용 메모
- 현재 `TECH_SPEC`엔 체력/쉴드/방어/공격/사거리 대부분이 이미 위 값과 일치(SC 기반 설계).
- **신규 적용 대상**: 각 유닛의 `cd`(공격 쿨다운 프레임), `mv`(이동 픽셀/프레임). 관리자 유닛 패널의 "공격속도" 칸에 `cd` 반영.
- 애드온 건물(컴셋·머신샵 등)과 진화/합체 유닛(가디언·아칸 등)은 게임 트리 구조에 맞춰 반영.
