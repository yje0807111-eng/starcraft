# 장비 아이콘

정비 > 장비 화면의 **착용 칸(`.pdSlot`)과 가방 칸(`.igCell`)** 안에 들어가는 그림.
파일이 없으면 코드에 내장된 라인아트 글리프(`PROF_SLOT_ICON`)로 자동 대체되므로,
**만든 것부터 하나씩 넣으면 된다.**

## ⚠ 다른 폴더와 다른 점 — 배경판을 그리지 않는다

`buildings/` `skills/` `upgrades/` 는 **어두운 금속판 + 리벳**을 그림 안에 포함한다(알파 없음).
장비는 반대다. **칸 자체가 판이고, 그 테두리가 등급을 말한다**(아래 「등급 프레임」).
그림이 자기 판을 들고 오면 판이 두 겹이 되고 등급 테두리가 묻힌다.

| 항목 | 값 |
|---|---|
| 크기 | **96 × 96** |
| 형식 | WebP · **알파 있음(배경 투명)** |
| 원본 | 384 × 384 PNG로 뽑아서 변환 |
| 배경 | **없음** — 물체만. 판·테두리·글로우·그림자를 그리지 말 것 |
| 시점 | 정면 · 회전/기울임 없음 (`skills/`와 같은 A 계열) |
| 여백 | 사방 8px 이상 — 칸 안에서 27px로 줄어든다 |

```bash
node -e "require('sharp')('in.png').resize(96,96,{fit:'contain',background:{r:0,g:0,b:0,alpha:0}}).webp({quality:86,alphaQuality:100}).toFile('out.webp')"
```

## 파일 이름

두 단계로 찾는다. 위에 있는 것이 먼저다.

| 이름 | 뜻 |
|---|---|
| `<부위>_<등급>.webp` | 그 부위의 **그 등급 전용** 그림 (예: `weapon_god.webp`) |
| `<부위>.webp` | 그 부위 **공용** 그림 — 등급 전용이 없을 때 (예: `weapon.webp`) |
| (없음) | 내장 라인아트 글리프 |

**부위 12종** — `helmet` `gloves` `top` `weapon` `bottom` `shoes`(장비) ·
`earring` `cape` `necklace` `sub` `ring` `belt`(장신구)

**등급 7종** — `common` `rare` `epic` `unique` `legend` `transcend` `god`

> 84장을 다 그릴 필요는 없다. 부위 공용 12장이 바닥을 깔고,
> 눈에 띄어야 하는 상위 등급만 전용 그림을 얹는 식을 권한다.

## ⚠ 넣은 뒤 목록에 등록할 것

없는 파일을 `src`로 걸면 칸마다 404가 난다(가방이 40칸이다).
그래서 **있는 파일만** 코드의 목록에서 꺼내 쓴다. `sc-ums-web.html`의 `GEAR_ART`에 키를 추가:

```js
const GEAR_ART = new Set([
  'weapon',            // assets/icons/gear/weapon.webp
  'weapon_god',        // assets/icons/gear/weapon_god.webp
]);
```

## 등급 프레임 (그림이 얹힐 바탕)

칸 테두리는 단계(1~7)가 오를수록 구조가 하나씩 붙는다. 그림은 이 위에 얹히므로
**색을 등급색에 맞출 필요가 없다** — 오히려 등급마다 색을 맞추면 테두리와 뭉개진다.

| 단계 | 등급 | 색 | 테두리에 더해지는 것 |
|---|---|---|---|
| 1 | 일반 | `#b8c0cc` | 판 + 윗변 광선 (기본) |
| 2 | 레어 | `#4aa8ff` | 테두리·광선이 등급색 |
| 3 | 에픽 | `#b06bff` | ＋ 아랫변 광선 |
| 4 | 유니크 | `#ffd23b` | ＋ 안쪽 링(이중 테두리) |
| 5 | 레전드 | `#ff8a3b` | ＋ 네 모서리 브래킷 |
| 6 | 초월 | `#ff4d6d` | ＋ 브래킷이 길어진다 |
| 7 | 갓 | `#ff2bd6` | ＋ 브래킷이 변을 거의 잇는다 |

색은 계정 공용 `TIER_COLOR`다(동료·펫과 같은 사다리). 여기서 새 색을 만들지 말 것.
