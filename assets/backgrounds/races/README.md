# 종족 전장 그림 (캠프 종족 선택 미리보기)

`union.webp` · `swarm.webp` · `aetherial.webp` 를 이 폴더에 넣으면 **코드 수정 없이** 뜬다.
파일이 없는 종족은 기본 그라데(`css/30-home.css` `#campRaceOv .crPrev`)로 그려진다.

## 규격
| 항목 | 값 |
|---|---|
| 파일명 | `union.webp` / `swarm.webp` / `aetherial.webp` (건설 트리 종족 키 = `stkTechRace()`) |
| 비율 | **9:16** — 폰 프레임을 `cover` 로 덮는다. 타이틀 배경(`title/boot.webp` 788×1400)과 같은 계열 |
| 권장 크기 | 1152 × 2048 |
| 형식 | WebP 품질 80 |

PNG 로 뽑았다면 이 폴더에 `.png` 로 넣고 `npm run img`.

## 구도 요구 — 타이틀 배경과 **반대**다
타이틀(`§8`)은 위쪽에 로고가 앉아 **위 1/3 을 비운다.** 여기는 아래에 종족 행과 확정 버튼이 앉으므로
**아래 1/3 을 비운다.** 그리고 제목이 좌상단에 있으므로 **왼쪽 위 모서리에 밝은 디테일을 두지 않는다.**

딤은 로딩과 같은 값(`.06 → .10 → .62 → .96`)으로 아래만 덮는다 — 그림이 어두우면 딤을 걷는 게 아니라
그림을 밝게 뽑는다(ART.md §7 ①).
