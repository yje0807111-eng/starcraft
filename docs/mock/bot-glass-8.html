기준 — 1안 (판 불투명 .86)

지금 가장 큰 배경 판은 rgba(6,8,12,.86) + 윗변 전폭 실선. 아래 여덟은 이 판 하나만 바꾼다 — 칸(작고 짙은 검정 네모)은 전부 그대로.

T1 — 그냥 옅게 (.86 → .55)

가장 단순한 한 줄. 전장의 색이 판 너머로 배어 나온다. 윗변 전폭 실선은 그대로라 경계는 여전히 또렷하다.

T2 — 세로 그라데로 (.22 → .93)

위는 거의 투명, 아래로 갈수록 짙게. 윗 경계 자체가 사라져 전장에서 콘솔로 자연스럽게 넘어간다. 로딩 딤과 같은 발상.

T3 — 옅게 + 짧아지는 윗변

.52 + 윗변을 좌우로 사라지는 헤어라인으로. 전폭 실선은 그림을 가로질러 아트를 '표'로 만든다 — 로그인이 전폭 선을 버린 그 이유.

T4 — 옅게 + 블러

.40 + backdrop blur 7px. 전장이 비치되 형태는 뭉개져 글자가 산다. ⚠ 저사양에서 블러는 비싸다(body.lite에서 꺼야 한다).

L1 — 로딩 딤 규격 그대로

판을 없애고 #titleBg::after 값을 그대로 쓴다 (.06 → .10(40%) → .62(74%) → .96). 로딩·로그인·타이틀이 쓰는 바로 그 곡선.

L2 — L1 + 국소 스크림 타원

L1 위에 #titleBg::before의 타원 스크림 한 장을 더한다. 「글자가 앉을 자리만」 어둡게 파는 장치 — 가운데가 짙고 끝은 0.

L3 — 로그인 문법 · 짧은 가운데 선

L1 + 머리줄을 가운데 정렬하고 구분선을 56px 짧은 가운데 선으로. 로그인 허브의 행 구분(.authWay+.authWay::before) 값 그대로.

L4 — 로딩 도크 문법 · 3px 막대

L1 + 머리줄 밑을 전폭 3px 막대로(.opBarWrap/.opBar 값 그대로 — 붉은 그라데 + 광). 라벨 자간도 로딩과 같은 .28em. 하단이 로딩 도크처럼 읽힌다.
