로그인 16안

지금 로그인 화면(#auth · .authCard)을 16가지로 다시 짰다. 앞 8안은 게임이 이미 쓰는 조형 언어 — 사냥터 카드 · .hmUp 금속 링 · .pdSeg 전등 · 시네마틱 팝업 · 이중 테두리 — 로만 조합했다. 뒤 8안은 지금 게임에 없는 방향을 일부러 넣었다. 규칙을 깨는 안은 어디를 깨는지 태그에 적었다.
내용(로고 · 방식 4개 · 게스트)과 화면 크기는 전부 같게 두고 껍데기와 배치만 갈랐다.

라운드 0 / 3 / 6 / 9만 테두리 1px 고정 · 굵히지 않고 겹을 늘린다 강조는 빛 · 면을 색으로 채우지 않는다 액센트 #ff3b3b (로그인 = 진입 화면 톤) 터치 타겟 ≥ 44px 볼륨 3 (진입 화면)

A · 어울리는 방향

기존 컴포넌트 조합 — 새 조형을 만들지 않는다

B · 색다른 방향

지금 게임에 없는 조형 — 규칙에서 벗어나는 곳을 태그에 적었다

지금 화면이 규칙에서 벗어난 곳 — 카드 모서리 컷 16px(0·3·6·9 밖) · 로고 font-weight:900(Jua는 400 단일 굵기라 가짜 볼드가 그려진다) · 안쪽 프레임 inset:5px(DESIGN §2 는 4px · 컷 길이도 카드와 같아야 한다).
⚠ 이 목업의 글꼴은 Google Fonts(Jua · Noto Sans KR · Rajdhani)로 근사했다 — 실제 앱은 같은 글꼴을 base64 로 내장해 쓴다. 자간·두께가 미세하게 다를 수 있다.
⚠ 안 6 · 12 는 assets/backgrounds/usemaps/ 의 키 아트를 빌려 썼다. 채택되면 로그인 전용 그림이 필요하다 — 규격은 ART.md 가 단일 소스다.
