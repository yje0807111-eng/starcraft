종족 선택 v2 — 8안 (로딩 · 로그인 · 설정 기반)

하단 시트를 버리고 처음부터 다시. 셋에서 실제로 쓰는 어휘만 조합했다 — 아트 풀블리드 + 아래만 덮는 딤 · 가운데 로고 축 · 글자만 행 + 짧은 가운데 선 · 전폭 헤어라인 행(좌 라벨 / 우 값) · 하단 도크(좌 라벨 + 우 큰 숫자 + 전폭 3px 막대).

세 화면에서 가져온 것 — 로딩: 아트 풀블리드 · 딤 `.06→.10→.62→.96` · 하단 도크 · 라벨 자간 .28em + 큰 값 23px · 전폭 3px 막대(색을 가진 건 이것 하나) · 로그인: 판 없음 · 가운데 축 · 글자만 · 짧은 가운데 선(56px) · 같은 무게 · 설정: 큰 제목 왼쪽 + ✕ · 전폭 헤어라인 행 · 좌 라벨 / 우 값·화살표 · 전폭 중립 버튼.
1 로그인 정본 · 판 없음 · 글자만
로그인 화면과 글자 하나 다르지 않다. 로고 축 아래 종족 셋이 글자로 놓이고, 짧은 가운데 선으로 갈린다. 확정은 게스트 줄과 같은 텍스트 + 밑변 광원. 가장 조용하고 규칙 위반 0. 대신 종족의 성격이 글자로만 전달된다.

로딩·로그인의 로고 블록 자리에 종족 이름이 크게 들어간다. `STAR WAR` 자리에 종족명(Jua 29px), `BATTLE ARENA` 자리에 부제. 종족을 바꾸면 이 덩어리가 크로스페이드된다 — 세 화면이 같은 자리에 같은 덩어리를 보여주는 규칙이 이어진다.

8 아트 전면 + 도크만 · 가장 조용
