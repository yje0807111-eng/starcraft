현행 — 기준

입력칸·전송 .55 / 조합 .95 — 나란히 있는데 하나만 두 배 진하다. 테두리 셋과 글자 둘이 전부 시안이고, 라운드는 6px.

C1 — 물성만 통일

셋 다 같은 면 rgba(6,8,12,.62) + 금속 테두리 + 3px. 시안은 뺀다. 가장 작은 변경 — 구조·배치는 그대로.

C2 — 입력칸만 판 · 버튼은 글자

적는 곳은 상자, 누르는 곳은 판 없이 글자 + 밑변 광원. 바로 아래 네비바와 같은 문법이라 하단이 한 어휘가 된다.

C3 — 셋 다 판 없음

입력칸도 밑줄 하나만. 로그인 문법 직역 — 전장이 가장 잘 보인다. 대신 스크림 한 장이 가독성을 맡아야 한다.

C4 — 트레이 한 판에 담는다

셋을 회색 판 하나에 담고 안에 검정 칸. 사냥터 스킬 바(.hbTray)와 같은 구조 — 「여기까지가 채팅」이 한 덩어리로 읽힌다.

C5 — 각진 컷

C1 + 모서리 대각 컷 7px(스킬 칸·트레이가 쓰는 계약). 하단 프로필 칸과 같은 실루엣이 된다.

C6 — 통일 + 전송만 강조

C1 + 전송에만 밑변 광원(주 버튼의 서명), 조합은 조용히. 같은 줄에 있는 둘의 위계를 만든다.
