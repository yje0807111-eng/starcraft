행 목록 5안

6-B(행 목록)로 확정하고 하단 블록을 올렸다 — 바닥 여백 26px → 78px. 나머지 넷은 같은 계열에서 행의 표기법과 여백만 갈랐다. 아트 3층 · 액센트 · 게스트 위계는 다섯 안이 전부 공유한다.

고정판 없음 — 헤어라인으로만 갈린다 고정주 방식 = 짧은 광선 하나 (화면에 1개) 고정게스트 = 텍스트 · 판 없음 고정터치 타겟 ≥ 44px 고정라운드 0 / 3만
올린 양은 토큰 하나(--lift)가 단일 소스다 — 다섯 안이 같은 값을 읽고, B4 만 더 올린다(86px). 실제 화면에 옮길 땐 고정 px 이 아니라 안전영역(safe-area) 을 더해야 한다: calc(var(--lift) + env(safe-area-inset-bottom)).
⚠ 배경은 assets/backgrounds/usemaps/temple.webp 를 비교용으로 빌려 썼다 — 다섯 안 모두 같은 그림이다. 확정되면 로그인 전용 키 아트가 필요하고 규격은 ART.md 가 단일 소스다. 구도 요구: 블록이 올라갔으므로 아래쪽 46%를 비울 것(원래 40%).
⚠ 글꼴은 Google Fonts 로 근사했다 — 실제 앱은 같은 글꼴을 base64 로 내장해 쓴다.
