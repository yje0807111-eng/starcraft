시네마틱 5안

16안 중 6번(시네마틱)을 고른 뒤, 지적하신 게스트 위계를 고치고 같은 결로 다섯 갈래를 냈다. 아트 3층(그림 → 비네트 → 오라)과 액센트는 다섯 안이 전부 공유하고, 갈리는 것은 조작 블록의 형태와 위치뿐이다.

먼저 — 게스트에서 빛을 뺀다

등급표기무엇에
① 주빨간 링 + 밑변 광원 화면에 하나뿐. 마지막에 쓴 방식(nm_last_auth)이 여기 온다 — 신규는 아이디
② 보조은색 링 · 광원 없음나머지 로그인 방식
③ 조용링 없음 · 글자만Google(잠김) · 게스트

밑변 광원은 이 앱에서 주 버튼의 서명이다(.authBtn · .pdSegInd 전등). 게스트에 붙이면 "기본 동작은 게스트"라고 말하게 된다 — 계정을 안 만들고 들어가는 길은 있되 권하지는 않는 자리가 맞다. 다섯 안 모두 게스트를 판이 아닌 텍스트로 내렸고, 그래도 터치 타겟 44px 는 유지한다.

아트 3층은 z-index 를 전부 명시한다 — 안 주면 비네트가 그림 아래로 깔린다(유즈맵 팝업에서 겪은 것).
⚠ 배경은 assets/backgrounds/usemaps/temple.webp 를 임시로 빌려 썼다. 다섯 안 비교를 위해 전부 같은 그림이다 — 확정되면 로그인 전용 키 아트가 필요하고, 규격·프롬프트는 ART.md 가 단일 소스다. 구도 요구: 아래쪽 40%를 비울 것(조작 블록 자리).
⚠ 글꼴은 Google Fonts 로 근사했다 — 실제 앱은 같은 글꼴을 base64 로 내장해 쓴다.
